# v3.33.0

> [!IMPORTANT]
> 如果已为 `openai.account_routing_override` 配置了值，且频繁遇到 `turn_rate_limit_exceeded`，建议将其改为 `null` 并重启服务
> 本版示例配置已将该项改为 `null`，升级不会自动修改已有配置

## 插件升级提醒

- 插件 RPC 协议从 v6 升级为 v7，宿主仅支持 v7；升级前请使用本版本 SDK 重新构建、打包并更新已安装插件，仅修改清单版本号不能完成升级

## 插件能力与运行状态

- 插件等待宿主回调时可归还执行名额，恢复处理前重新取得名额；统一回调结果的驻留、消费和取消回收，修复交叉调用可能因执行容量相互等待的问题
- 认证、账号授权和模型目录查询与模型执行准入分离；账号授权、模型目录和显式 Key 执行复用同一父调用内的身份与权限快照
- 新增客户端认证、账号与模型授权检查、完整额度事实查询，以及按指定账号当前代理发送 HTTP 请求的 SDK 能力
- 插件管理页展示实际运行状态，缺少诊断时明确显示未知；详情新增当前会话的运行负载，包括在途、执行、排队、恢复等待、回调和活动流

## OpenAI 错误透传

- 修复上游 WS 错误转换为 SSE `response.failed` 时，客户端无法读取事件级 `Retry-After` 的问题；有效等待建议补入 `response.error.headers`，并优先保留错误对象已有的有效值

## 模型选择

- 已选但当前上游目录未返回的模型保留原有选中样式，通过警示图标说明，悬浮或点击可查看完整模型 ID 和提示；浮层中的长名称自动换行，简中、繁中和英文同步
- 目录尚未取得、加载中或请求失败时不误报模型缺失；刷新按钮移至模式选择器一行的最右侧，并保持等高和常态底色
