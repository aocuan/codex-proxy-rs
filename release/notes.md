# v3.32.0

## 升级提醒

- 插件 RPC 协议升级为 v6，不兼容旧协议；升级宿主前请准备使用本版本 SDK 重新构建的插件包，并更新已安装插件

## 插件调用与维护

- 支持插件按调用阶段声明处理时长，宿主与 SDK 使用同一份预算；移除统一 120 秒截断，维护任务默认预算从 30 秒调整为 120 秒，插件可显式声明更长或更短的有限时长
- 注册、配置、CLI、重试等调用按所属实例和阶段计时；外部请求期限、网络操作期限及取消仍独立生效，长预算不提供跨重启续跑
- 无关配置发布不再打断正在执行的维护任务；停用或替换实例时，等待旧任务取消确认或进程退出后再启动替代任务，避免维护重叠
- 维护诊断补充预算来源、实际耗时与结束原因，便于区分超时、失败和主动取消

## OpenAI 请求配置

- 新增 `openai.account_routing_override`，与 `openai.residency` 统一为可选字符串；填写值原样发送，不校验地域或路由枚举，省略或 `null` 时删除对应下游请求头且不补发
- 示例配置两项均为 `us`，注释列出参考值；配置独立于管理端客户端身份，修改后重启生效，切换身份或刷新客户端版本不会覆盖
- WebSocket 连接池按账号路由头区分连接，并区分空字符串与未配置，避免复用携带不同握手头的连接
